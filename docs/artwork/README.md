# Fork artwork

The shared Android and desktop startup artwork is `src/android/app/src/main/res/drawable-nodpi/dekui_launcher_masks.png`: a cel-shaded group of the Deku, Fierce Deity, Zora, and Goron masks. Both launchers contain the full group in the former clock area on the left, leaving the menu clear on the right. The Deku flower at `drawable-nodpi/deku_flower.png` supplies app, splash, notification, and inherited desktop branding variants. The former clock-face and standalone Fierce Deity launcher backgrounds are removed.

These are fork branding assets, separate from user-ROM-generated Adult Link models and voices. Third-party source credits and license notices remain intact.

Menus use Liberation Sans under its SIL Open Font License; the font license is bundled in `src/android/app/src/main/assets/dekui-fonts/LICENSE.txt`. No external launcher artwork or typography is required.
