Dekui for Windows x64

Extract the entire ZIP into a writable location. Open the dekui folder, then
run Dekui.exe.
Keep its DLLs, plugins, tools, resources, and runtime folders together.
Windows 10/11 x64 and a Vulkan-capable graphics driver are required.
A private Python runtime is included for setup and resource upgrades.
No separate Python installation or PATH changes are needed.

Put exactly one decrypted USA v1.1 game-card dump (.cci or .3ds) beside
Dekui.exe, then launch it. Any filename is accepted. Use a game card with v1.1
preinstalled. First launch silently prepares the included Restoration and
HD HUD layouts in user/ before opening the game. Allow extra time on first launch. No file-selection prompts or mod downloads are needed.
The game is used in place, never moved or duplicated. Keep it beside Dekui.exe;
missing/unsupported games block gameplay.
Project Restoration is included with its license and matching source under
resources/mm3d/project-restoration. Game files are not included.

Press F1 for General, Graphics, HUD, Difficulty, Restoration, QOL, Audio,
Controls and About. Fresh setups start at 4x resolution; existing settings
are preserved.
Game touchscreen input is disabled.
Updating: close Dekui and back up the entire user/ folder. Extract the new
release into a separate writable folder, then copy user/ and your game beside
the new application.
Launch the new version. Saves, preferences, textures and unrelated mods are preserved.
Recognized older menu layouts update with backups; customized layouts are kept.
General > Reset menu layouts restores the current menu layouts if needed.
If an upgrade is interrupted, relaunch to retry. Keep user/ and upgrade backups.
The application is unsigned.
Source and licenses accompany the download. Report errors without sharing ROMs,
keys or saves.

Optional custom textures: use F1 > Graphics > Open texture folder, install a
compatible pack, enable Use custom textures, then restart Dekui. The folder is
user/load/textures/0004000000125500/. Texture packs are not included.
