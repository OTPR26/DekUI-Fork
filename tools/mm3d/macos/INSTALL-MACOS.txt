DekUI Fork — Apple Silicon, macOS 13.4 or newer

Extract the ZIP and open DekUI Fork.app. The app contains its setup tools,
resources and Python runtime; no developer tools are required.
Select your own decrypted MM3D USA Rev 1 (.cci/.3ds) ROM at startup. Selected
ROMs and texture packs stay in their existing locations.

Saves, settings, generated mods, logs and caches are stored in:
~/Library/Application Support/DekUI Fork/
On first launch, data from an older portable user folder beside the app is
copied there and verified before use. The old folder remains as a backup.
Existing Application Support data is never overwritten by a portable copy.
macOS may ask for access to external game/texture folders you select.

Settings is available on the startup screen. During gameplay, use the DekUI
Fork > Settings menu or Command-comma. F1 also works. On a controller, press
Start + Select together; menu confirmation follows your saved game bindings.

Settings > Graphics contains custom texture-folder selection. Point it at your
existing MM3D texture pack. Folder changes apply on the next game launch.
Settings > Mods contains OoT3D ROM and optional texture-pack selection and
Generate Adult Link / Generate Dark Link. Generate before starting gameplay.
Models include adult voices; Adult Link includes original green/blue/red tunic
variants and an optional Master Sword. Restart gameplay after changing models.
No ROMs, models, voice banks, texture packs or saves are included in this ZIP.

Touch > Swap screens shows the game's touchscreen for mouse input. Swap back
to return to the single-screen game. In-game cheats need a loaded save.

Updating: close DekUI Fork and replace the app. Your Application Support
data stays in place. Back up that folder before making manual changes.
For the first upgrade from the portable version, place the updated app beside
the existing user folder so it can migrate your saves and settings once.
Never delete your saves to fix setup problems.

This app is ad-hoc signed and not Apple-notarized. If macOS
blocks it, use System Settings > Privacy & Security > Open Anyway. Move the
entire extracted folder with Finder if macOS isolates the downloaded app.
Intel Macs are not supported by this package.

In-game Reset warns about unsaved progress, then returns to the startup screen
while keeping the app open. Mods > ROM and texture setup uses that confirmation
and opens startup Settings > Mods directly. Quit on the startup screen exits.
